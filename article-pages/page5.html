React 19.2 is Here: Understanding the New <Activity> Component

Sarah Jenkins

Principal Engineer • Oct 28, 2025

8 min read

Released in Oct 2025, React 19.2 brings the new Activity API for better state preservation and Offscreen rendering.

For years, React developers have faced a common dilemma: how do you hide a component without losing its state? If you unmount it (using conditional rendering), the state is destroyed. If you use CSS (display: none), the component keeps rendering in the background, consuming valuable CPU cycles.

With the release of React 19.2 this week, the team has finally solved this with the stabilization of the <Activity> component (previously known experimentally as Offscreen).

The "Unmount" Problem

Consider a simple Tab interface. When a user switches from "Tab A" to "Tab B", we usually stop rendering Tab A. 

function App() {
  const [tab, setTab] = useState('home');

  // ❌ When this switches, the old component unmounts.
  // All input data and scroll positions are lost.
  return (
    <>
      {tab === 'home' && <HomeTab />}
      {tab === 'profile' && <ProfileTab />}
    </>
  );
}

Enter the <Activity> Component

The new API allows you to mark a part of your tree as "hidden" but kept alive. React will put the component into a special hibernation mode. It won't render updates (saving CPU), but its state remains frozen in memory.

"Activity allows high-priority updates to skip hidden trees, while preserving their state for instant restoration."

Here is how the new syntax looks in React 19.2:

import { Activity } from 'react';

function App() {
  const [tab, setTab] = useState('home');

  return (
    <>
      <Activity mode={tab === 'home' ? 'visible' : 'hidden'}>
        <HomeTab />
      </Activity>

      <Activity mode={tab === 'profile' ? 'visible' : 'hidden'}>
        <ProfileTab />
      </Activity>
    </>
  );
}

How it works under the hood

When mode="hidden" is set:

  • Visuals: React applies display: none to the root DOM node.
  • Effects: Layout effects are unmounted, but state is preserved.
  • Priority: React lowers the priority of any updates happening inside the hidden tree, so they don't block the main thread for visible UI.

When should you use it?

Don't wrap everything in <Activity>. It consumes memory. The best use cases we have found at Nexus Tech include:

  • Complex Forms: Where users might tab away to check info and return.
  • Data Tables: Preserving sort order and scroll position.
  • Infinite Lists: Avoiding the expensive re-initialization of virtualization libraries.

React 19.2 is available now via npm install react@latest.
